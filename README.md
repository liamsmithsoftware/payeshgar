# 📡 پایشگر (Payeshgar)

سامانه یکپارچه خزش و پایش **وب**، **تلگرام** و **شبکه ایکس (X)** همراه با سیستم کنترل دسترسی مبتنی بر نقش (**ACL**).

## ویژگی‌ها

- **صفحه اولیه با سه محیط کاملاً مستقل**:
  - 🌐 **محیط وب**: خزش وب‌سایت‌ها (به‌غیر از شبکه ایکس و تلگرام).
  - ✈️ **محیط تلگرام**: خزش کانال‌ها و صفحات عمومی تلگرام (`t.me`).
  - 𝕏 **محیط ایکس**: مشابه محیط وب، اما **فقط** لینک‌های شبکه ایکس (`x.com` / `twitter.com`) را می‌پذیرد.
- **سیستم ACL کامل**:
  - ورود با **نام کاربری، رمز عبور و کپچای ریاضی**.
  - تعریف نقش‌های دلخواه توسط ادمین و تخصیص دسترسی از سطح کلی (مشاهده بخش) تا اکشن‌ها (`crawl`، `delete`، `create`، `edit`).
- **تفکیک پایگاه داده‌ها**:
  - `instance/users.db`: پایگاه داده کاربران، نقش‌ها و دسترسی‌ها.
  - `instance/workspace.db`: پایگاه داده فضای کاری و نتایج خزش هر سه محیط.

## اجرا

```bash
pip install -r requirements.txt
python3 app.py
```

برنامه روی پورت `5000` اجرا می‌شود.
