# 📡 پایشگر (Payeshgar)

سامانه یکپارچه **خزش، پایش زمان‌بندی‌شده و آرشیو هوشمند** شامل هر سه محیط کامل و مستقل **وب**، **تلگرام** و **شبکه ایکس (X)** همراه با سیستم **مدیریت دسترسی مبتنی بر نقش (ACL)** و ورود امن با **کپچا**.

---

## ویژگی‌های کلیدی

1. **صفحه اول فقط لاگین + باز شدن بخش‌ها بر اساس دسترسی:**
   - در ورود اولیه به سامانه فقط صفحه ورود (نام کاربری + رمز عبور + تصویر کپچای ۴ رقمی) نمایش داده می‌شود.
   - پس از ورود، تنها محیط‌ها و عملیات‌هایی که نقش کاربر به آن‌ها دسترسی دارد باز و نمایش داده می‌شوند.

2. **سه محیط کاملاً مستقل با ۱۰۰٪ امکانات مخازن اصلی:**
   - 🌐 **محیط وب (`/web/`)**: دقیقاً منطبق بر مخزن اصلی خزشگر وب شامل کشف خودکار RSS/Atom/JSON-Feed، وب‌سرویس وردپرس، نقشه سایت، خزشگر HTML و مرورگر، تست اتصال (`probe`)، پروکسی اختصاصی هر وب‌سایت، زمان‌بند ۳۰ ثانیه‌ای، خروجی Excel (`.xlsx`) و SQLite (`.sqlite`)، پشتیبان‌گیری و بازیابی JSON، حذف انتخابی/فیلترشده و پاک‌سازی. *(لینک‌های شبکه ایکس و تلگرام در بخش وب پذیرفته نمی‌شوند).*
   - ✈️ **محیط تلگرام (`/telegram/`)**: دقیقاً منطبق بر مخزن اصلی خزشگر تلگرام شامل دریافت ترکیبی (`t.me/s/` + موتور رسمی `Telethon` برای کانال‌های خصوصی)، زمان‌بند خودکار، جلوگیری از تکرار با `message_id`، خروجی Excel و SQLite، پشتیبان‌گیری JSON و پاک‌سازی پیشرفته.
   - 𝕏 **محیط ایکس (`/x/`)**: دقیقاً منطبق بر مخزن اصلی آرشیو شبکه ایکس (فقط لینک‌های `x.com` و `twitter.com` قابل پذیرش هستند)، پایش زمان‌بندی‌شده، بازنشانی نشانگر بدون حذف آرشیو، خروجی Excel و SQLite، پشتیبان‌گیری JSON و پاک‌سازی.

3. **سیستم ACL کامل (۲۷ سطح دسترسی از سطح کلی تا اکشن‌ها):**
   - دسترسی‌های مجزا برای هر محیط: `view` (مشاهده)، `sources` (افزودن/ویرایش منابع)، `crawl` (همگام‌سازی فوری)، `export` (خروجی Excel/SQLite/پشتیبان)، `settings` (تنظیمات/پروکسی/بازیابی)، `delete` (حذف و پاک‌سازی).
   - مدیریت کامل کاربران (`users.*`) و نقش‌ها (`roles.*`) در پنل مدیریت (`/admin`).

4. **تفکیک کامل پایگاه داده کاربران و فضای کاری:**
   - پایگاه داده کاربران و ACL: `data/users/users.db`
   - پایگاه‌های داده مستقل محیط‌های کاری:
     - وب: `data/workspace/web/web_collector.sqlite`
     - تلگرام: `data/workspace/telegram/telegram_collector.sqlite`
     - ایکس: `data/workspace/x/x_collector.sqlite`
